# 🎨 React Native Figma UI

Project ini adalah implementasi desain dari **Figma** ke aplikasi **React Native**.
Tampilan dibuat semirip mungkin dengan desain, lengkap dengan background image, custom font **Plus Jakarta Sans**, dan tombol modern.

## ✨ Fitur

* 🖼️ **Custom Background** sesuai layout Figma (ukuran & posisi mengikuti desain).
* 🔠 **Custom Font**: Plus Jakarta Sans (Regular & Bold).
* 🎨 **Modern Button** dengan shadow & rounded corner.
* 🌗 **Support Dark/Light Theme** via `useColorScheme`.
* 📐 Struktur file dipisah rapi (`screens`, `styles`, `assets`).

---

## 🛠️ Instalasi

1. Clone repo:

   ```bash
   git clone https://github.com/username/react-native-figma-ui.git
   cd react-native-figma-ui
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Link custom font:

   ```bash
   npx react-native-asset
   ```

4. Jalankan di Android:

   ```bash
   npm run android
   ```
